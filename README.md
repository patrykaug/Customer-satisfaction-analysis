# Customer Satisfaction & Purchase Intention Analysis

## Project Overview

This project applies **machine learning methods** to analyse customer satisfaction and predict future purchase intentions in a supermarket.

The analysis focuses on two main problems:

- **Regression** – predicting the level of customer satisfaction.
- **Classification** – predicting whether a customer intends to shop at the supermarket again.

The project covers the complete analytical workflow, including data preprocessing, exploratory analysis, model development, model evaluation and interpretation of results.

---

## Machine Learning Models

### Regression

Models used to predict customer satisfaction:

- K-Nearest Neighbors
- Random Forest
- Extra Trees

Models were evaluated using regression performance metrics such as **RMSE and R²**.

### Classification

Models used to predict future purchase intention:

- Logistic Regression
- Decision Tree
- Random Forest

The classification models achieved an accuracy of approximately **82–83%**.

In addition to accuracy, models were compared using:

- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC analysis

The models produced relatively similar predictive performance, while the **Decision Tree offered particularly straightforward interpretation of the classification process**.
